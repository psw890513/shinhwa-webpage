# 다음 작업 계획

`writing-plans` 스킬 기준. 위에서부터 순서대로 한다. 각 단계는 끝나면 `npm test`로 확인하고 `main`에 합친다.

1. **실제 회사 정보 넣기** — `index.html`의 placeholder(`00-0000-0000`, `OO`)를 실제 값으로 바꾼다. 필요: 점검표 2번 칸의 회사 정보
2. **Firebase 연결** — README 안내대로 프로젝트 생성, `js/firebase-config.js` 입력, `firestore.rules` 배포, 관리자 계정 등록. 확인: 견적 요청이 관리자 접수 내역에 뜨는지
3. **실제 장비 등록** — 관리자 페이지에서 보유 장비, 규격, 사진, 임대료(공개할 경우) 등록
4. **도메인 연결** — 구매 후 GitHub Pages Custom domain 설정, 검색엔진 등록
5. **현장 질문 반영** — 점검표 3번 칸 답변을 받아 문구, 자주 묻는 질문, 장비 순서에 반영
