GitHub 연결

수정한 내용은 GitHub 저장소에 저장되고 1~2분 뒤 사이트에 반영됩니다. 처음 한 번만 아래 순서대로 토큰(비밀 키)을 넣어 주세요. 연결 전에도 내용을 둘러보고 고쳐 볼 수는 있지만 저장은 되지 않습니다.

  1. GitHub 토큰 만들기 화면을 엽니다 (GitHub 로그인 필요).
  2. Token name에 "신화 사이트 관리", Expiration은 원하는 기간(최대 1년)을 고릅니다.
  3. Repository access에서 Only select repositories → shinhwa-webpage를 고릅니다.
  4. Permissions → Repository permissions → Contents를 Read and write로 바꿉니다.
  5. Generate token을 누르고 나온 github_pat_로 시작하는 값을 복사해 아래에 붙여 넣습니다.

토큰은 이 기기의 브라우저에만 저장됩니다. 공용 컴퓨터에서는 쓰지 마세요.

연결됨 저장하면 GitHub에 바로 기록되고 1~2분 뒤 사이트에 반영됩니다.
