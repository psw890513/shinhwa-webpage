# 사진 폴더

## equip/ — 장비 그림 (직접 그린 SVG)

장비 사진이 없을 때 카드와 배너에 쓰는 그림입니다. 저작권 걱정 없이 쓸 수 있습니다.

| 파일 | 쓰는 곳 |
|---|---|
| equip/generator.svg | 발전기 |
| equip/pump.svg | 엔진양수기 |
| equip/motor.svg | 수중모터 |
| equip/compressor.svg | 공기압축기 (기타 장비 기본값) |
| equip/welder.svg | 용접기 |

## 실제 사진으로 바꾸기

관리자 화면 → 제품 수정 → "사진 주소"에 사진 주소를 넣으면 그 장비 카드에 사진이 나옵니다.
이 폴더에 사진을 넣었다면 `images/파일이름.jpg` 처럼 적으면 됩니다. 정사각형(1:1) 사진이 카드에 가장 잘 맞습니다.

다른 회사 홈페이지나 쇼핑몰의 사진은 저작권이 있으니 쓰지 마세요.
